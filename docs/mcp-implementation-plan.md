# План реализации MCP для Mihomo

Работа выполняется в текущем каталоге, самостоятельно, без worktree, commit, push и обращения к роутеру.

Согласованный объём: локальный MCP через stdio; SSH запускает фиксированные операции установленного watchdog. Замер выбранного узла и поиск более быстрого используют существующий BENCHMARK, настройки замеров и общий lock. Поиск по умолчанию только показывает результат; применение требует отдельного аргумента и локального разрешения в настройках сервера. Секрет контроллера остаётся на роутере.

Подход: Python SDK отдельно от Entware runtime. Альтернативы — дублирование алгоритма на компьютере или MCP на роутере — добавляют дублирование либо зависимости на роутере. В текущем варианте весь тестовый трафик идёт с роутера. Тестируется пропускная способность загрузки, а не текущий пользовательский трафик.

- [x] Добавить CLI с JSON-ответом, stderr для журналов, общей блокировкой и явной ошибкой busy; автоматический failover не менять.
- [x] Добавить локальный MCP-сервер: два инструмента, фиксированные SSH-команды, ключевая аутентификация, запрет применения по умолчанию, контролируемые ошибки. Проверить транспорт тестами.
- [x] Описать установку и подключение; проверить unit-тесты, реальный MCP stdio с SDK, синтаксис, diff и обновление graphify.

Ограничения: тесты контроллера и SSH используют моки; реальный роутер и IPK требуют отдельной проверки. BENCHMARK и target_group должны содержать конкретный выбранный provider-backed узел. Изменения конфигурации, рестарты и расширенная диагностика не входят в эту итерацию.

## Результат

Все 88 тестов прошли в окружении uv с PyYAML и MCP SDK, включая реальный stdio-клиент/сервер с подставным SSH. Проверки Python/shell-синтаксиса, `git diff --check` и отсутствия кириллицы в технических исходниках пройдены. Независимый обзор не выявил блокирующих замечаний. Выполнен `graphify update .`: 477 узлов и 790 связей. Роутер, реальный контроллер и сборка IPK не проверялись; установка и публикация не выполнялись.

## Расширение: сервис замеров и конфигурация

Согласованный запрос: вынести сервис загрузки в настройку и разрешить MCP изменять только настройки схемы router-watchdog.json. Минимальный подход: поле speed_test_url (HTTP(S), шаблоны {bytes}/{cache_bust}); частичный patch через stdin фиксированной SSH-команды, строгая проверка имён/типов/диапазонов на роутере, атомарная запись 0600 под общим lock. Чтение скрывает secret, обновление возвращает только имена изменённых полей и признак необходимости sync-cron. Не добавляются произвольные пути или shell-команды.
