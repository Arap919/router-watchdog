# Документация router-watchdog

Начните с [карты проекта](project-map.md), затем прочитайте [согласованный дизайн](failover-design.md).

- [Карта проекта](project-map.md): файлы, компоненты, пути на роутере, сборка и локальные проверки.
- [Дизайн failover](failover-design.md): согласованные требования, алгоритм, аварийное переключение, изоляция замеров и критерии приёмки.
- [План реализации](implementation-plan.md): порядок изменений и проверок.
- [Проектный скилл](../.agents/skills/router-watchdog-context/SKILL.md): навигация для моделей ИИ.

По состоянию на 15 октября 2026 года согласованный алгоритм реализован и проверен локальными тестами. На роутер изменения не применялись, пакет не публиковался. В карте проекта указаны ограничения проверки и прежнее несоответствие ссылки `Other` имени группы `other` в личном Mihomo-конфиге.

Технические справочники и инструкции для ИИ написаны на английском, пользовательские пояснения и план — на русском.
